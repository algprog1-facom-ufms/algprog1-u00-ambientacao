## Desafio 03 — Sobre mim (em Markdown)

Os arquivos `README.md` de todos os repositórios são escritos em **Markdown**. Neste
desafio você vai escrever o seu primeiro.

1. Na pasta `05-desafios/`, crie um arquivo com o nome **exatamente**
   `desafio03_sobre_mim.md`.
2. Escreva nele:
   - um **título** (linha começando com `# `) com o seu primeiro nome ou apelido;
   - uma **lista** com pelo menos **3 itens** (linhas começando com `- `), por exemplo:
     o que você espera aprender, um hobby e uma curiosidade sobre você;
   - (opcional) uma palavra em **negrito**, escrevendo-a entre `**dois asteriscos**`.
3. Faça commit + push e abra o arquivo no GitHub para ver como ficou formatado.

Exemplo:

```markdown
# Marina

- Quero aprender a criar jogos.
- Nas horas vagas, toco **violão**.
- Já visitei o Pantanal três vezes.
```

> 🔒 Não escreva dados pessoais como telefone, endereço ou documentos.
