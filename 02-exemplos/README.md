# 02 — Exemplos

Programas curtos para você executar e confirmar que o ambiente está pronto. Para cada um:

1. **Leia** o código e tente imaginar a saída.
2. **Execute** no terminal, a partir da raiz do repositório:
   ```bash
   python 02-exemplos/ex01_hello.py
   ```
   Também é possível usar o botão **Run Python File** (▷) no canto superior direito do
   editor.
3. **Compare** com o que você imaginou.
4. **Altere** algo e execute de novo. Errar aqui não custa nada!

| Arquivo | O que mostra |
|---|---|
| `ex01_hello.py` | O primeiro programa: duas mensagens com `print` |
| `ex02_verificar_ambiente.py` | Confere a versão do Python e o sistema (você vai usar a saída na atividade 06) |
| `ex03_erro_proposital.py` | Um erro de sintaxe proposital, para aprender a ler a mensagem de erro |

> ℹ️ Não se preocupe em entender todo o código do `ex02`: ele usa recursos que veremos
> mais adiante. Nesta unidade, basta executá-lo.
