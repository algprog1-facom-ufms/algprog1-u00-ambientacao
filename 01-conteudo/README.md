# 01 — Conteúdo

Leia os guias na ordem. Os guias 4 e 5 são de **instalação**: faça cada passo no seu
computador enquanto lê. Cada guia termina com uma lista **"Verificação"** — se você
conseguir marcar tudo, siga para o próximo.

| # | Guia | Ideia central |
|:-:|---|---|
| 1 | [A disciplina e como vamos trabalhar](01-a-disciplina.md) | Cada unidade é um repositório com o mesmo roteiro: conteúdo → exemplos → PRIMM → atividades → desafios → autoavaliação. |
| 2 | [Primeiros passos com GitHub](02-github.md) | Conta, username, repositório e commit — e como manter sua conta segura. |
| 3 | [Como funcionam as atividades no Classroom 50](03-classroom50.md) | Você aceita a atividade, recebe um repositório só seu e cada `push` é corrigido automaticamente. |
| 4 | [Instalação do Python](04-python.md) | O interpretador que executa seus programas. |
| 5 | [VS Code e Git](05-vscode-e-git.md) | O editor onde você vai programar e o Git, que registra e envia suas alterações. |
| 6 | [O ciclo de trabalho de cada atividade](06-ciclo-de-trabalho.md) | Clonar → editar → executar → commit → push → conferir o resultado. |
| 7 | [Inteligência Artificial e integridade acadêmica](07-ia-e-integridade.md) | Quando e como a IA pode ser usada em cada fase da disciplina. |

Depois do conteúdo, vá para [`02-exemplos/`](../02-exemplos/).
