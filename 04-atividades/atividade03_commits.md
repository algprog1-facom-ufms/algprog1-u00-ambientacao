# Atividade 03 — Commits e mensagens de commit                       (10 pontos)

Releia o [guia 6](../01-conteudo/06-ciclo-de-trabalho.md). Em cada questão, marque
**uma única** alternativa trocando `[ ]` por `[x]`.

---

**Questão 1.** Você corrigiu um acento que faltava na saída da atividade 02. Qual é a
melhor mensagem de commit?

- [ ] (1a) `ajustes`
- [ ] (1b) `Corrige acento na saída da atividade 02`
- [ ] (1c) `asdfgh`

**Questão 2.** Você terminou o desafio 01. Qual é a melhor mensagem de commit?

- [ ] (2a) `final`
- [ ] (2b) `agora vai!!!`
- [ ] (2c) `Resolve desafio 01 (apresentação)`

**Questão 3.** Qual comando **envia** os seus commits para o GitHub?

- [ ] (3a) `git commit`
- [ ] (3b) `git add .`
- [ ] (3c) `git push`

**Questão 4.** Você fez o commit no VS Code, mas a correção automática não rodou e nada
apareceu em **Releases**. Qual é a causa mais provável?

- [ ] (4a) Faltou fazer o push.
- [ ] (4b) O Python não está instalado.
- [ ] (4c) O arquivo precisa ser renomeado.

---

Depois de marcar, faça um commit com uma **boa** mensagem — você acabou de aprender
como escrevê-la.
