# 04 — Atividades de ambientação

Estas atividades treinam o **ciclo de trabalho** da disciplina: editar um arquivo,
executar, fazer `commit` + `push` e conferir o resultado em **Releases**.

Resolva na ordem. Cada arquivo traz o enunciado no topo. Faça um **commit para cada
atividade** — é um ótimo treino.

| # | Arquivo | O que pratica | Pontos |
|:-:|---|---|:-:|
| 01 | `atividade01_ficha.md` | Editar um arquivo Markdown e fazer o primeiro push | 10 |
| 02 | `atividade02_primeiro_commit.py` | Escrever e executar um programa | 8 |
| 03 | `atividade03_commits.md` | Commit, push e mensagens de commit | 10 |
| 04 | `atividade04_combinados.md` | Combinados da disciplina e uso de IA | 7 |
| 05 | `atividade05_corrigir_erro.py` | Ler mensagens de erro e corrigir o programa | 10 |
| 06 | `atividade06_ambiente.md` | Verificar Python e Git pelo terminal | 10 |
| | | **Total** | **55** |

## Como testar antes de enviar

Execute os programas a partir da **raiz** do repositório:

```bash
python 04-atividades/atividade02_primeiro_commit.py
```

Compare a saída com o **exemplo de execução** do enunciado, caractere por
caractere: acentos, vírgulas, pontos, espaços e maiúsculas contam.

Nos arquivos `.md`, marque as caixas trocando `[ ]` por `[x]` (sem espaços extras) e
escreva as respostas **na mesma linha** do campo indicado.

## Erros que mais tiram pontos

- Esquecer um acento ou a pontuação final.
- Fazer o commit e esquecer o **push**.
- Renomear ou mover o arquivo.
- Escrever `[ x]` ou `( x )` em vez de `[x]`.
