Esta atividade confirma que o Python e o Git estão funcionando **no seu computador**.

1. No terminal integrado do VS Code, a partir da raiz do repositório, execute:

   ```bash
   python 02-exemplos/ex02_verificar_ambiente.py
   ```

   (no macOS/Linux, `python3`). **Copie toda a saída** e cole no primeiro bloco abaixo.

   ```bash
   git --version
   ```
